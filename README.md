# EHDS EEHRxF Cross-Border Clinical Gateway

A European Health Data Space (EHDS) reference implementation demonstrating Primary Use data exchange under Chapter II and Article 14.

## Overview
This gateway transforms national Electronic Health Record (EHR) data formats into the European Electronic Health Record Exchange Format (EEHRxF) using HL7® FHIR® profiles.

## Scope
- Patient Summary (IPS / HL7 Europe profile)
- ePrescription & eDispensation
- Conformance & Terminology Validation (SNOMED-CT, LOINC, ATC)
